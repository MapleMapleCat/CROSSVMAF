01OVERVIEW

Two videos in. One score out.

CrossVMAF compares a reference video with a distorted video. Feature evaluation runs on a Vulkan GPU; final model prediction runs on the CPU. Every frame is scored, and pooling condenses the sequence into a single 0–100 result.

ref.mp4×dist.mp4

Reference + distorted

Two inputs with matching decoded dimensions, pixel format, bit depth, and frame count. No resizing, no color conversion — compared exactly as decoded.

frame n↔frame n

Frames paired, features on GPU

Decoded frames pair in display order with timestamp checks. The VMAF 1.0.16 feature set is extracted in Vulkan compute on any vendor's GPU.

0–100

A pooled 0–100 score

Per-frame scores pool by mean, min, or harmonic mean. Export JSON or CSV from the CLI — or an A4 PDF report from Studio.

02HIGHLIGHTS

Built like an instrument.

Vulkan compute

Feature evaluation runs on any Vulkan 1.1+ GPU — Intel, NVIDIA, AMD, or others. Cross-vendor by design, not by port.

Five decode paths

QSV, NVDEC, AMF, Vulkan Video, and VA-API — picked automatically per GPU vendor, with a software fallback always behind them.

Automatic model selection

Eight bundled VMAF 1.0.16 models chosen from the reference's decoded dimensions and frame rate — 4K, 1080p, and HFR variants, with CLI overrides.

CPU verification

--verify-cpu decodes again and runs an independent CPU reference pass, comparing it against the Vulkan results frame by frame.

Pooling your way

Mean by default. Min and harmonic mean when the worst frames matter more than the average ones.

Reports & exports

JSON and CSV from the CLI. Studio adds A4 customer PDF reports — pooled score, quality curve, distribution, review segments — with fonts embedded.

03PIPELINE

GPU where it pays, CPU where it counts.

DECODE

auto backend

Per GPU vendor: Intel QSV · NVIDIA NVDEC · AMD AMF (Windows) / VA-API (Linux) → Vulkan Video → software.

FEATURES

vulkan compute

The VMAF 1.0.16 feature set is evaluated in compute shaders on the selected Vulkan device.

TEMPORAL

across frames

Motion and temporal features aggregate across frames on the GPU.

MODEL

svm on cpu

The bundled model matched to your input predicts per-frame scores on the CPU.

SCORE

mean · min · harmonic

Pooling condenses the sequence into a single 0–100 score, recorded in every report.

04STUDIO

A desktop lab for your queue.

Studio wraps the engine in a desktop workflow: select inputs, queue evaluations, compare saved runs, and review reports — in English or 简体中文, light or dark.

  • Queue with confidence

    Settings are captured the moment a task is enqueued; the queue pauses on failure by default instead of burning through the batch.

  • Compare runs

    Overlay quality curves from saved evaluations in four color-blind-safe series colors.

  • Reports that travel

    Export JSON or CSV for analysis, or generate an A4 customer PDF — pooled score, curve, distribution, review segments — with fonts embedded. No browser or printer driver needed.

06C++ API

        
Stream results as frames land.

        
Embed CrossVMAF in your own pipeline. Open an EvaluationStream on the two paths; next() returns ordered batches, and finish() drains the remaining GPU and temporal results.

      

      

        

          
Ordered batches
Results arrive in display order as the GPU pipeline produces them — no waiting for the whole sequence.

          
Full control
Cancellation, metadata, frame-count hints, and execution statistics through the public streaming API.

        

        

          

            stream.cpp
            
          

          
#include <crossvmaf/crossvmaf.hpp>

crossvmaf::StreamOptions options;
options.reference_path = "reference.mp4";
options.distorted_path = "distorted.mp4";

auto opened = crossvmaf::EvaluationStream::open(std::move(options));
if (!opened) { /* opened.error().message */ }

auto stream = std::move(opened).value();
for (;;) {
  auto batch = stream->next();          // ordered batches
  if (batch->empty()) break;
  consume(batch.value());
}

auto tail = stream->finish();          // drain GPU + temporal tail
