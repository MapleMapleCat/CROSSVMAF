# Icon sources

`folder-open.svg`, `film.svg`, `file.svg`, `file-chart-column.svg`, `copy.svg`,
`info.svg`, `arrow-right.svg`, `monitor.svg`, `palette.svg`, `activity.svg`, `chevron-right.svg`, `chevron-down.svg`, `plus.svg`, and `x.svg` are unmodified icons from
[Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons).
Their license is included in `LICENSE-lucide.txt`. Slint colors the monochrome
assets using the existing Studio theme.

The other icons predate the home-screen redesign.
